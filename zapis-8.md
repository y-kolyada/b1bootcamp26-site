## Запись 8

**Кто делал:** ИИ (Claude Code). **Кто проверяет:** тренер курса.

**Сначала - откуда взялось это задание.** По программе на занятии 8 каждый показывает пять вещей: ссылку на продукт, репозиторий, одно задание с предикатами, один возврат и проверку, которая ловит поломку. Тренер предложил собрать эти пять вещей в презентацию - деку сдачи, которую участник делает со своим Claude Code. Так у показа появляется порядок, а у приёмки - предмет.

**Уточнения тренера к черновику, до задания.**

1. **Образца деки на странице нет.** ИИ предложил дать как образец формы деку, которую тренер показывал перед курсом. Тренер вернул это: увидев ссылку, агент будет машинально копировать, а деки должны быть разными и своими. Поэтому промпт называет только, что должно быть в деке, а оформление участник описывает своими словами.
2. **Дека и файлом, и артефактом.** ИИ предложил файл `sdacha.html` на GitHub Pages вместо артефакта claude.ai. Тренер принял файл, но артефакт тоже нужен: кто-то из участников захочет опубликовать деку и там.
3. **Ни репетиций, ни числа слайдов.** Кто захочет репетировать - репетирует. На странице остался только формат сдачи: около четырёх минут показа и минута на приёмку.
4. **Страница нужна в день занятия 7.** В конце занятия 7 тренер рассказывает участникам о формате занятия 8.

**Что ИИ сказал, что сделал:**

- добавил `08.html` - страницу занятия 8: пять канонических блоков, девять шагов на трёх путях (пять на пути-минимум, по два на пути-100% и пути-максимум);
- три промпта в шагах с якорями: «Собери деку сдачи» (`#min-2`), «Проверка помнит и деку» (`#min-3`), «Сделай из деки артефакт» (`#sto-1`), и список в блоке `#tri-promta`;
- блок `#format-sdachi`: около четырёх минут показа, минута на «принять» или «вернуть» по одному предикату, и что возврат - не провал;
- один образец - `#obrazec-zadaniya`: предикаты про деку чужой викторины, помечен как форма, а не содержание. Образца оформления деки на странице нет;
- семь заглушек `08-*.html`; занятие 8 открыто в навигации всех 72 прежних страниц. Слова «будет» в навигации больше нет;
- `check.sh`: занятие 8 в списке страниц, в мультиязычности и под предикатом 13;
- `programme.md` в репозитории курса: занятие 8 говорит про деку в двух местах и про минуту приёмки, а «До следующего раза» занятия 7 - «собираешь деку по странице занятия 8».

**Артефакт сверен с документацией, а не взят по памяти.** Источник - страница про артефакты на `code.claude.com` и страница доступности функций. Там сказано:

- создавать артефакты Claude Code может только при входе через аккаунт claude.ai, на тарифах Pro, Max, Ultra, Team или Enterprise; при входе по ключу API - нет;
- нужна версия Claude Code 2.1.281 или новее;
- местом названы Claude Code в терминале и приложение Claude для компьютера, а окно Claude Code в VS Code не названо;
- новый артефакт виден только владельцу, открыть его по ссылке можно кнопкой Share на странице артефакта.

Поэтому шаг про артефакт стоит на пути-100%, в терминале, и начинается с `claude --version`. Бесплатный тариф в таблице Claude Code не назван, а справочная статья claude.ai говорит про него иначе. Страница не обещает ни того, ни другого: если артефакт не создаётся, хватает деки на GitHub Pages.

**Решение по дороге: имя в деке проверяют глазами.** Задание просило, чтобы раздел «Задание 8» держал «в деке нет имени и фамилии». Но чтобы машина искала имя, его надо написать в `check.sh`, а `check.sh` уходит на GitHub, где его видят все. Проверка выдала бы то, что должна охранять. Поэтому в промпте строка «имени и фамилии нет - глазами», а на странице сказано почему. Это тот же приём, что на занятии 7: что машина не может проверить честно, проверяется глазами и так и подписано.
